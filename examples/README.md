# examples · 模板渲染示例

本目录的 HTML 文件是 **模板的真实渲染效果**（固定 1920×1080 舞台、浏览器直接打开）：

| 文件 | 效果 |
|---|---|
| `template-gallery.html` | **一页看全部 20 套模板**的缩略标题页（推荐先看这个） |
| `demo-deck-blue-professional.html` | Blue Professional **完整 8 页演示 deck**（方向键翻页），看整套效果 |

双击任意一个文件即可在浏览器查看（页面会按窗口等比缩放，键盘方向键翻页）。

## 查看全部 20 套模板

模板设计规范在 `bold-template-pack/templates/<模板名>/`，每套两个文件：

- `design.md` — 完整设计系统（字体 / 配色 / 版式 / 组件 / CJK 适配），模型定稿后读取
- `preview.md` — 风格卡（调性 / 适合场景 / Signature moves），用于出预览

## 生成自己的示例

安装 skill 后对模型说（内容会换成你的）：

```
帮我做一个看板：主题：本月运营数据；内容：工单 320 单，解决率 95%，平均响应 2.1 小时
```

模型先给 3 张风格预览（从 20 套模板里推荐），选定后生成单文件 HTML。
