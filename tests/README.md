# tests · 自检

## 自检项

1. 生成一个最小 HTML 页（内容随意），用浏览器打开确认可渲染、无报错。
2. 分别从 `bold-template-pack/` 的 20 套模板中挑 3-4 套各生成一页，确认风格差异明显、无"AI slop"（默认字体 / 俗渐变 / 千篇一律的卡片布局）。
3. 确认输出是单文件、固定 1920×1080 舞台、整体等比缩放（窗口拖到手机宽度时内容不重排、不溢出）。
4. 确认生成页内没有模板名、slug、路径、"preview" 等内部文案。
5. 中文内容时确认 CJK 字体回退正确（每套模板的 design.md 都有 CJK 适配说明）。

## 通过标准

- 所有生成页双击可开、渲染正常
- 不同模板视觉上明显不同
- 单文件零外部依赖（字体 CDN 链接除外）
- 任意视口下保持 16:9、无文字截断、无面板互相遮挡
